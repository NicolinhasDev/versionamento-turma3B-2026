Relatorio de versionamento de código.


O que eu lembro:

O que é Versionamento de Código
O versionamento de código é o processo de gerenciar e rastrear todas as alterações feitas nos arquivos de um projeto de software ao longo do seu ciclo de vida. Ele funciona como uma certidão de nascimento e um diário de bordo do sistema, documentando cada modificação, por quem foi feita e o motivo.

Repositorio - É o local onde o Git armazena todos os arquivos de um projeto, além de todo o histórico de alterações feitas neles.

GitHub - O GitHub é uma plataforma que guarda o código-fonte e arquivos em nuvem que utiliza o sistema de controle de versão Git.

Repositório Local - Fica armazenado diretamente no disco rígido do computador do desenvolvedor. É onde o código é escrito, modificado e testado. Funciona totalmente offline.

Repositório Remoto - Fica guardado em um servidor na internet ou rede interna (como GitHub, GitLab ou Bitbucket). Ele serve como o ponto central para a equipe compartilhar o código, fazer backups e centralizar a versão oficial do projeto.


COMMIT - Serve para salvar e alterar dados.
PUSH - Subir algo no arquivo.
PULL - É o inverso do PUSH.
GIT - Registra cada alteração que fez projeto e mostra quem fez a alteração,quando foi feita e o que foi alterado do código.
GIT CLONE - cria um clone do seu repositorio.
GIT ADD - Adiciona os arquivos na fila para o commit.
GIT PUSH - Envia as alterações locais para o remoto.
GIT PULL - Puxa as atualizações do nosso repositorio remoto para o local.
GIT BRANCH - Cria uma nova BRANCH

BRANCH -  é uma linha de desenvolvimento separada dentro do projeto.
MAIN / MASTER - Código que está rodando (o aplicativo que usa).




Relatorio de Back-End.

O que eu lembro:

O que é Back-End

O Back-end é a parte de um sistema ou site que fica nos bastidores. Ele cuida do servidor, do banco de dados e da lógica do sistema, processando as informações que o usuário não vê diretamente.

APIs - Os "caminhos" que permitem que o que você vê no celular converse com o servidor.
Linguagens de programação -  Ferramentas usadas para escrever o código do servidor, como Python, Node.js (JavaScript), Java e PHP.

comandos:

SELECT -  Busca dados guardados.
INSERT - Salva novos dados.
UPDATE - Atualiza dados existentes.
DELETE - Apaga informações. 



REST (Representational State Transfer): O modelo mais usado na web atual por ser leve e flexível. Usa o protocolo HTTP e troca dados principalmente em formato JSON.

GraphQL: Criado pelo Facebook, permite que o cliente peça exatamente os dados que precisa, nem mais, nem menos. Evita requisições repetidas.

SOAP (Simple Object Access Protocol): Um modelo mais antigo, rígido e altamente seguro. Usa o formato XML e é muito comum em sistemas bancários e governamentais.
